# Wi-Fi Network Scanner

## Project Overview
A Python-based desktop application that scans nearby Wi-Fi access points and displays their network information.

## Features
- Scan nearby Wi-Fi networks
- Refresh network information
- Display SSID
- Show signal strength
- Display security type
- Show frequency band and channel
- Count detected access points

## Technologies Used
- Python
- Tkinter
- Windows Netsh Command

## How to Run
1. Install Python on Windows.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Run:

```bash
py app.py
```
